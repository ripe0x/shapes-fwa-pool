# Remove the position ceiling with incremental accounting and efficient journal jobs

PackVault keeps one authoritative incremental book instead of a300-position ceiling and portfolio scans. Paid Shapes mints, recipes, creator fees and protected holder liabilities remain. Provably unexposed history advances unpaid, preserving the 0.01 ETH seed and first-deposit pricing.

Journal jobs now read up to 128 completed global records independently of 16 own transitions,16 terminal IDs and16 pruned heads. Callers cannot select a smaller paid slice. Small foreign tails require a genuine fresh checkpoint opportunity; distribution-only tails authenticate actual post-cost gain and liquidity. Sync uses routine upkeep even during redemption; existing caller-funded unlisting/liquidation stays intact.

The durable keeper index discovers returns from actual ETH/token bid events, retains unseen selections, independently discovers expiry and replays newly relevant history on upgrade. Restock keeps immediately consumed minted IDs in memory and shares economics reads before minting.

## Things that don't make sense

- **Repeated harvesting breaks once-per-cycle expense assumptions.** The timely candidate model makes 990 harvest calls and pays 0.266081233333330390 ETH against 1.819168941380021572 gross fee income. Gross fees also compensate lost backing. Its completed exit includes 44 underpaid holder harvest calls; completion is not funded operation.
- **The inherited daily model was unsuitable for operating acceptance.** Its10^12-second settlement surrogate differed from actual 3600 seconds. The new opt-in clock uses actual expiry and separate blackout timing, but generated counterparty timing, static foreign pool and gas proxies remain conditional. Neither model establishes annual returns or a budget recommendation.
- **Permission supplies no ETH.** More allowance cannot release protected holder cash or solve a returned-pack reconciliation/liquidation cash cycle. That particular finding remains model/source evidence, not an authentic fork reproduction. Mint revenue is separate and is not an assumed subsidy.
- **Receipt scope matters.** Refunded entries cannot establish exposed successful-foreign costs. The combined maximum own-transition job remains unmeasured. The earlier 342,766 checkpoint bound double-subtracted finalized refunds and is withdrawn; the actual standalone 346,017 bill supersedes that claim.
- **Foreign staging can block admission.** Another actor must clear that staging. The authentic multi-allocation live returned-pack scenario remains narrower than historical-payload index/restart/reorg coverage.

**Keep this PR draft.** No allowance increase, minimum TVL, mint-fee change, recurring sponsorship, public-chain transaction, real funds, owner outcome signature or merge. This is focused implementation verification, not a full security audit or release approval.
